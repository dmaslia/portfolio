# Portfolio Project Technical Overview

## System Architecture

### Frontend Stack
React 19.1.0 + Vite 6.3.5
- Production build via Vite
- Nginx static file serving
- Responsive design with dynamic sizing
- Dual-view: Resume + RAG Chatbot

### Backend Stack
Express 5.1.0 + FastAPI
- ES modules architecture
- OpenAI API integration
- Python RAG service
- dotenv for config
- CORS security

### Deployment
Ubuntu VPS + Nginx
- SSL/TLS via Let's Encrypt
- PM2 process management
- Automated deployment
- Resource monitoring

## RAG Implementation

### Document Processing
PDF/TXT Support:
- PyPDFLoader for PDFs
- TextLoader for TXT
- Auto-type detection
- Text preservation

Chunking Strategy:
- Size: 300 chars
- Overlap: 30 chars
- Separators: ["\n\n", "\n", ".", " "]
- Preserves paragraphs

### Vector Store
Chroma + HuggingFace:
- Model: sentence-transformers/paraphrase-MiniLM-L6-v2
- Persistent storage
- Efficient search
- Metadata tracking

### Query Flow
1. Express receives query
2. Forwards to FastAPI
3. Vector search (k=15)
4. Context formatting
5. OpenAI completion

Search Details:
- Chroma similarity
- Context management
- 5s timeout
- Error handling
- Fallback system
