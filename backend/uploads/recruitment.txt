
HPE
I worked on the NonStop team at HPE. During my internship, I learned the ins and outs of the NonStop proprietary operating system, along with the scripting and coding languages that are used in the operating system codebase. To assist with the latest release of the OS, I developed a system tool that monitors semaphore usage across the operating system. This tool gave the team key insights into the way synchronous threads behave within a multithreaded process.

MDP
Through the University of Michigan's Multidisciplinary Design Program and Caterpillar Inc, I am working in a team of students to create an optimization model and web application that informs construction fleet managers of strategies to best utilize their fleet. Given user inputted fleet criteria and constraints, the model outputs actions that will allow the user to minimize cost and fleet emissions while maximizing fleet productivity. We are working with Python libraries such as scikit and selenium for web scraping and data analysis.
